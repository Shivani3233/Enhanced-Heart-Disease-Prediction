System Architecture

A deep dive into how CardioPredict's multi-layer architecture turns raw clinical data into calibrated, actionable risk predictions.

End-to-End Pipeline

DATA INGESTION
Clinical Dataset
3,070 patient records × 16 features
Feature Engineering
27 features (age groups, BMI cats, interactions)
Stratified Split
70% train / 15% calibration / 15% test
FEATURE SELECTION
BorutaSHAP
SHAP-value based all-relevant selection (20 trials)
mRMR
Max-relevance, min-redundancy filtering (12 features)
Union Merge → Robust Scaling
BASE MODELS + BAYESIAN OPTIMIZATION
IWRF
Weighted Random Forest with iterative boosting
LightGBM
Histogram-based gradient boosting
CatBoost
Ordered boosting with balanced weights
EasyEnsemble
Balanced bagged AdaBoost ensemble
All tuned via BayesSearchCV (5-fold stratified CV)
ENSEMBLE & POST-PROCESSING
Soft Voting
F1-weighted probability averaging across 4 models
Isotonic Calibration
CalibratedClassifierCV on held-out calibration set
Threshold Optimization
Youden's J statistic for optimal cutoff
PRODUCTION OUTPUT
Risk Prediction
Low / Moderate / High with calibrated probability
Confidence Score
Calibrated probability + risk-level color coding
Recommendations
Personalized lifestyle and medical guidance

Model Artifacts

The training pipeline exports these serialized artifacts, loaded at server startup for real-time inference.

File Description
optimized_heart_disease_model.pkl Calibrated soft-voting ensemble (IWRF + LightGBM + CatBoost + EasyEnsemble)
robust_scaler.pkl RobustScaler fitted on selected features (IQR-based normalization)
feature_selector.pkl BorutaSHAP + mRMR combined feature list and index mapping
optimal_threshold.pkl Youden's J optimized decision threshold (float)
training_results.json Full metrics summary: accuracy, F1, ROC-AUC, PR-AUC, Brier score, etc.
