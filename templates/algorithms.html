Feature Selection

BorutaSHAP Feature Selection

Combines the Boruta all-relevant feature selection algorithm with SHAP (SHapley Additive exPlanations) values for robust, interpretable feature selection. Instead of relying on traditional importance metrics, it uses game-theoretic SHAP values to measure each feature's true contribution to predictions.

How It Works
  • Creates "shadow" copies of all features by random permutation
  • Computes SHAP values for both real and shadow features using a LightGBM model
  • Features consistently outperforming their shadow counterparts are confirmed as relevant
  • Runs 20 statistical trials for high-confidence selection
Explainable AI Game Theory Statistical Testing
Feature Selection

mRMR — Minimum Redundancy Maximum Relevance

A powerful information-theoretic feature selection method that balances two objectives: maximizing the mutual information between each feature and the target variable (relevance), while minimizing redundancy among the selected features themselves.

How It Works
  • Computes mutual information between each feature and the target class
  • Greedily selects features that add maximum new information
  • Penalizes features that are highly correlated with already-selected ones
  • Result: a compact, diverse, and highly predictive feature set

Improved Weighted Random Forest (IWRF)

A custom enhancement of the standard Random Forest that incorporates dynamic sample weighting and iterative refinement. Misclassified samples receive boosted weights in subsequent iterations, creating a feedback loop that forces the forest to focus on hard-to-classify cases.

How It Works
  • Initializes sample weights based on inverse class frequency (cost-sensitive)
  • Trains a balanced-subsample Random Forest with current weights
  • Identifies misclassified samples and boosts their weights by 50%
  • Repeats for multiple iterations, progressively improving boundary decision
Ensemble Learning Adaptive Boosting Class Imbalance
Base Model

LightGBM — Light Gradient Boosting Machine

A highly efficient gradient boosting framework developed by Microsoft that uses histogram-based learning and leaf-wise tree growth for faster training and lower memory usage. It natively supports imbalanced datasets through the is_unbalance parameter.

How It Works
  • Uses Gradient-based One-Side Sampling (GOSS) to focus on poorly predicted samples
  • Exclusive Feature Bundling (EFB) reduces feature space for speed
  • Leaf-wise growth finds the split with maximum loss reduction
  • L1/L2 regularization prevents overfitting on medical data
Gradient Boosting Histogram-based Microsoft Research
Base Model

CatBoost — Categorical Boosting

Developed by Yandex, CatBoost implements ordered boosting to combat prediction shift (a form of target leakage common in gradient boosting) and handles categorical features natively without manual encoding. Its auto_class_weights='Balanced' mode applies cost-sensitive learning automatically.

How It Works
  • Ordered Target Encoding for categorical features prevents data leakage
  • Ordered Boosting uses permutation-based training to reduce overfitting
  • Symmetric (balanced) decision trees for GPU-efficient inference
  • Built-in class weighting adjusts the loss for minority classes
Gradient Boosting Ordered Boosting Yandex Research
Base Model

EasyEnsemble

An ensemble strategy specifically designed for class-imbalanced learning. It creates multiple balanced subsets by under-sampling the majority class and trains a separate AdaBoost classifier on each subset. The final prediction aggregates all sub-classifiers through majority voting.

How It Works
  • Randomly under-samples the majority class to create balanced subsets
  • Trains 15 independent AdaBoost classifiers on these subsets
  • Each sub-learner becomes expert on different regions of the data space
  • Final prediction aggregates all sub-learners for robust, bias-corrected output
Imbalanced Learning Under-sampling Meta-classifier
Optimization

Bayesian Optimization

A sequential model-based optimization strategy for hyperparameter tuning. Unlike grid search or random search, Bayesian optimization builds a probabilistic surrogate model (Gaussian Process) of the objective function, then uses an acquisition function to intelligently choose the next set of hyperparameters to evaluate.

How It Works
  • Defines search spaces for each model's hyperparameters
  • Builds a Gaussian Process surrogate model of the cross-validation F1 score
  • Uses Expected Improvement (EI) acquisition to balance exploration vs exploitation
  • Converges on optimal hyperparameters in 20-25 iterations per model
Gaussian Processes Acquisition Functions Hyperparameter Tuning
Training Strategy

Cost-Sensitive Learning

In medical diagnosis, missing a disease case (false negative) is far more costly than a false alarm (false positive). Cost-sensitive learning assigns asymmetric misclassification costs: a false negative costs 5× more than a false positive, forcing the model to prioritize high sensitivity.

How It Works
  • Defines a cost matrix: FN = 5×, FP = 1× (asymmetric penalties)
  • All base models use class_weight='balanced' or equivalent
  • IWRF uses inverse-frequency sample weights amplifying minority class
  • Evaluation includes total-cost metric alongside standard metrics

Post-Processing

Probability Calibration

Raw model outputs from boosted ensembles are often poorly calibrated — a predicted probability of 80% may not correspond to an 80% true positive rate. Isotonic regression calibration maps these raw scores to well-calibrated probabilities that doctors can trust for clinical decision-making.

How It Works
  • Holds out a calibration set (15% of data) from training
  • Fits an isotonic regression model on (raw_probability → true_outcome) pairs
  • Produces monotonic, non-parametric mapping from raw → calibrated probabilities
  • Validated using Brier Score and reliability diagrams
Isotonic Regression Brier Score Clinical Trust
Post-Processing

Threshold Optimization

Rather than using the default 0.5 decision threshold, we optimize it using Youden's J statistic (Sensitivity + Specificity − 1). For medical screening, this approach maximizes the ability to correctly identify both positive and negative cases, often lowering the threshold below 0.5 to favor sensitivity.

How It Works
  • Generates ROC curve from calibrated probabilities on calibration set
  • Computes Youden's J = TPR − FPR at every possible threshold
  • Selects threshold that maximizes J (optimal operating point on ROC)
  • Also evaluates best-F1 threshold as an alternative for comparison
