## 🎯 Overview

**CardioPredict** is a cutting-edge web application that leverages advanced machine learning algorithms to predict heart disease risk with **94.2%+ accuracy**. Built with **Flask** and powered by **ensemble ML models**, it delivers instant cardiovascular risk assessments through a beautiful, responsive dark-themed interface.

### 🎯 Mission
To democratize cardiovascular health screening through AI technology, making advanced heart disease risk assessment accessible to everyone while maintaining clinical-grade accuracy.

## ✨ Features

### 🧠 AI-Powered Prediction Engine
- **Ensemble Models**: Random Forest, Gradient Boosting, Extra Trees, Neural Networks
- **Advanced Feature Engineering**: Age groups, BMI categories, risk interactions
- **Cross-Validation**: 5-fold stratified validation
- **Hyperparameter Optimization**: GridSearchCV for peak performance

### 💻 Beautiful User Interface
- **Dark Theme**: Professional medical-grade dark interface
- **Heart-Themed Design**: Cardiovascular color scheme & animations
- **Responsive Layout**: Optimized for desktop, tablet, and mobile
- **Accessibility**: WCAG 2.1 compliant with keyboard navigation

### 📊 Comprehensive Analysis
- **Risk Factor Assessment**: 16+ medical parameters
- **Visual Risk Meter**: Interactive probability visualization
- **Personalized Recommendations**: Tailored lifestyle & medical advice
- **Detailed Reporting**: Full breakdown of risk factors

### 🔒 Security & Privacy
- **No Data Storage**: All data processed and immediately discarded
- **HIPAA-Compliant**: Secure handling of sensitive medical data
- **Server-Side Processing**: No client-side model exposure

## 🚀 Installation

### Prerequisites
- Python 3.8 or higher
- `pip` package manager
- Virtual environment (recommended)

### Step-by-Step Setup

```bash
# 1. Clone the repository
Extract the zip file
cd cardiopredict

# 2. Create and activate virtual environment
python -m venv venv

# On Windows:
venv\Scripts\activate

# On macOS/Linux:
source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the app
python app.py

Access the Application
Open your browser and go to:
👉 http://localhost:5000
